# Descripción #

El proyecto consta de un supuesto caso de análisis de datos, junto con el cálculo de varias medidas y dimensiones, para conocer aspectos futbolísticos del pasado mundial, del mes de julio del 2026, en EE.UU., Canadá y, México. Tal proyecto muestra las diferentes selecciones que lo conforman, el número total de goles, tarjetas amarillas y rojas que obtuvieron y el potencial valor de mercado que puede tener cada jugador, en función del papel que haya hecho durante todo el torneo.
 
 La adquisición de los datos ha sido a través de Kaggle (https://www.kaggle.com/), concretamente del usuario "Rohan Prashanth" (https://lnkd.in/eBYEpf8J).
